# 점검

1. `npm test`를 실행합니다. 실패하면 출력을 인용하고, 원인이 어느 담당 영역(콘텐츠 또는 프론트엔드)에 있는지 판단합니다.
2. 다음 명령으로 토픽별 문제 수와 노트 섹션 수를 표로 만듭니다.
   ```bash
   node scripts/validate.mjs --coverage
   ```
3. 문제가 5개 미만인 토픽, 노트가 없는 토픽, `exam.verified: false` 상태를 "다음 작업 제안"으로 정리합니다. 제안마다 어떤 스킬이나 에이전트를 쓰면 되는지 함께 적습니다.
