# 새 기능 워크플로

요청: $ARGUMENTS

1. **설계 (메인 에이전트)**
   - `CLAUDE.md`와 `site/js/app.js`의 구조를 확인합니다.
   - 수용 기준을 3~6개 정합니다. 각 기준은 "사용자가 무엇을 하면 무엇이 보인다"는 형태로, 확인할 수 있게 씁니다.
   - 데이터 스키마를 바꿔야 하는 기능이면 진행하기 전에 사용자에게 확인합니다.
2. **구현**: `frontend-dev` 에이전트에게 요청 내용, 수용 기준, 관련 파일을 넘깁니다.
3. **콘텐츠가 필요하면** `content-writer`나 `question-author`를 병렬로 실행합니다.
4. **검토**: `qa-reviewer`를 실행합니다. 이때 수용 기준과 변경된 파일 목록도 함께 넘깁니다.
5. qa-reviewer가 `치명` 또는 `중요` 문제를 보고하면 담당 에이전트에게 다시 보내 고치게 하고, 4단계부터 다시 합니다. 최대 3회까지 반복합니다.
6. 사용자에게 보고합니다: 구현한 내용, 수용 기준별 충족 여부, `npm test` 결과, 남은 `경미` 이슈.
